How to read this report

Ready for CTO sign-off

First-level audit is clean. The LOB CTO can sign off adoption.

Audit done, adoption in progress

The UI audit report is issued. Dev teams are closing the comments, or the product is in cross audit.

Not completed

Install not shared, install shared but audit not started, or audit still in progress.

  • Stages are grouped from the sheet's Current Status column.
  • QA is the quality certification for the release. "Requires regression" means the code came from a hotfix branch and needs another validation round after it reaches the main branch.
  • CHECK marks a sign-off-ready line that also shows regression required or 0% dev coverage in the sheet.
  • Presales environments follow their product audit. Green means the install is shared, blue means waiting for the product audit to close, red means nothing shared yet.
  • Wholesale Banking = Wholesale in the sheet; Consumer Banking = Consumer.
